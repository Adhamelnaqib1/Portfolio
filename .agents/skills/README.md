# Workspace Skills

Add your custom skill folders here. Each skill must be placed in its own subdirectory and contain a `SKILL.md` file.

### Example Directory Structure

```text
.agents/skills/
└── your-skill-name/
    ├── SKILL.md          # Required
    ├── scripts/          # Optional: Helper scripts
    ├── references/       # Optional: Reference docs
    └── examples/         # Optional: Code snippets or templates
```

### Template: `SKILL.md`

```markdown
---
name: your-skill-name
description: >-
  Describe what this skill does and when the agent should activate it.
  e.g., "Use this skill when the user asks to update portfolio projects or deploy the site."
---

# Your Skill Title

Write clear, step-by-step instructions or procedures for the agent here.
```
